# KBÜ Not Hesaplayıcı

## Proje Hakkında
Bu proje, Karabük Üniversitesi öğrencilerinin ders başarı notlarını hesaplayabilmesi için hazırlanmıştır.

## Projenin Amacı
Öğrencilerin vize, yıl içi çalışma, final ve bütünleme notlarını girerek başarı notlarını ve harf notlarını kolayca öğrenmelerini sağlamak.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Özellikler
- Not hesaplama
- Final ve bütünleme desteği
- Harf notu gösterimi
- Devamsızlık ve sınava girmeme kontrolü
- Basit ve kullanışlı tasarım

## Hesaplama
Başarı notu, yıl içi notunun %40'ı ve final veya bütünleme notunun %60'ı alınarak hesaplanır.

## Nasıl Çalıştırılır?
`index.html` dosyası tarayıcıda açılarak veya Visual Studio Code üzerinden Live Server kullanılarak çalıştırılabilir.
